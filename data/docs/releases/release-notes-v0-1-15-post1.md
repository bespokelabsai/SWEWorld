# Release notes: v0.1.15.post1

Patch release on top of v0.1.15. One change only.

## What changed

- **Packaging fix**, the v0.1.15 distribution was broken in certain installation environments. This release corrects that and nothing else.

## Upgrade notes

- No API changes between v0.1.15 and v0.1.15.post1
- If v0.1.15 installed and ran without issue for you, this release is still safe to take (i.e. nothing regresses)
- If v0.1.15 failed to install, upgrade to v0.1.15.post1 and the packaging issue should be resolved

## Notes

I dont have a precise list of which environments were affected by the v0.1.15 packaging problem. If you saw an install failure on v0.1.15 and v0.1.15.post1 does not fix it, open an issue.
