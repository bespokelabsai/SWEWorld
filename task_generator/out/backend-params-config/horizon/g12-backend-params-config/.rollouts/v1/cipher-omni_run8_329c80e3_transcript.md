6. **Added `_resolve_mode(batch, backend)`** — `"offline"` if vllm (beats `batch=True`), else `"batch"` if batch, else `"online"`.

8. **Rewrote `_validate_backend_params(params, batch, backend)`** to validate against only `_MODE_CONFIGS[_resolve_mode(batch, backend)]` and return an instance of that class. The first-match-wins loop and the trailing `ValueError` are gone.

### `_factory.py` changes

1. **`_create_config`** is now exactly `return _validate_backend_params(params, batch, backend)`.
