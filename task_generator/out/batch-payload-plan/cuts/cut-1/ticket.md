# Batch payload planner for `batch_size="auto"`

Replace the ad-hoc sizing loop that `batch_size="auto"` uses today with a pure, testable planner. Add a new module `src/bespokelabs/curator/request_processor/batch_payload_planner.py` exporting: `@dataclass(frozen=True) class BatchLimits` with fields `max_requests_per_batch: int` and `max_bytes_per_batch: int`; `@dataclass(frozen=True) class PlannedBatch` with fields `index: int`, `start_idx: int`, `end_idx: int`, `num_requests: int`, `num_bytes: int`; `def payload_size_bytes(payload: dict) -> int`; `def payload_bytes(sizes: Sequence[int]) -> int`; `def plan_batches(sizes: Sequence[int], limits: BatchLimits) -> list[PlannedBatch]`; and `class BatchPayloadTooLargeError(ValueError)` whose `__init__(self, *, num_requests: int, size_bytes: int, limit_bytes: int) -> None` stores `num_requests`, `size_bytes`, `limit_bytes` as attributes. On `BaseBatchRequestProcessor` (`request_processor/batch/base_batch_request_processor.py`) add a `batch_limits` property returning `BatchLimits(max_requests_per_batch=self.max_requests_per_batch, max_bytes_per_batch=self.max_bytes_per_batch)`, a `measure_request_payload(self, generic_request: GenericRequest) -> int`, and a `plan_request_batches(self, dataset: "Dataset") -> list[PlannedBatch]` that builds each row's request through the existing `PromptFormatter.create_generic_request` and returns a plan honouring both limits; `create_batch_file(self, api_specific_requests: list[dict])` keeps its signature (return annotation corrected from `str` to `bytes`) and raises `BatchPayloadTooLargeError` where it raises `ValueError` today. In `base_request_processor.py`, delete the nested `_get_optimal_batch_size` helper (lines 263‑278) and the `while True` loop (lines 282‑295) and drive the `"auto"` branch of `create_request_files(dataset: Optional["Dataset"]) -> list[str]` (unchanged signature) off `self.plan_request_batches(dataset)`, writing each planned batch through the existing `acreate_request_file(...)` as `requests_{i}.jsonl` with `metadata_{i}.json`. The explicit-integer `batch_size` branch (lines 297‑311) keeps its current behaviour exactly: `ceil(len(dataset) / batch_size)` fixed-width files filtered by `incomplete_files`, no byte-based resplit, no planner call. `max_requests_per_batch` / `max_bytes_per_batch`, `create_api_specific_request_batch`, `acreate_request_file` and `run_in_event_loop` are reused as-is. Tests build processors via `__new__` with `config`, `prompt_formatter`, `working_dir`, `_cost_processor` assigned by hand and patch the two limit properties with `unittest.mock.PropertyMock`; no network, no clients, no sleeps.
