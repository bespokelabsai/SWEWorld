- The explicit-integer `batch_size` branch is unchanged: `ceil(len(dataset) / batch_size)` fixed-width files filtered by `incomplete_files`, no byte-based resplit, no planner call

### Key design details

- The planner measures the **provider payload** (`create_api_specific_request_batch`), not the generic request, and `payload_bytes` accounts for the `n-1` newline separators so that `plan[i].num_bytes == len(create_batch_file(api_specific_requests_for_span_i))` exactly.
- `SingleRequestTooLargeError` is raised eagerly during planning when a single request exceeds the byte limit, instead of the old code's `batch_size = idx` returning `0` (which caused an infinite hang/zero-progress loop).
- Tests can build processors via `__new__` with `config`, `prompt_formatter`, `working_dir`, `_cost_processor` assigned by hand and patch the two limit properties with `unittest.mock.PropertyMock` â no network, clients, or sleeps required.
