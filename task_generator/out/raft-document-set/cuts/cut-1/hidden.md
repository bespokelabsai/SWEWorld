# Hidden requirements — g13 (raft-document-set)

## r1
- **rule** — In the oracle-present branch the pre-shuffle list is built distractors-first, in the order the sampler returned them, with the oracle document APPENDED AT THE END (the current code prepends it at raft.py:156); the whole list is then permuted by exactly one self.rng.shuffle(...) call. For a given rng state and sampler this fixes one specific permutation, not merely one distribution.
- **scope** — Applies to every uncached document-set build, and both branches consume the same shape of rng stream, in this order: (a) exactly one self.rng.random() compared `< self.p` to decide oracle_present; (b) exactly one self.sampler(available_indices, k) call with k = self.distractors when the oracle is present and k = self.distractors + 1 when it is absent, available_indices being [i for i in range(len(self.chunks)) if i != chunk_id] in ascending order; (c) exactly one self.rng.shuffle(...) over the assembled list — in the oracle-absent branch too, not only the present one.
- **exclusions_or_crossover** — oracle_index is carried through the shuffle by a per-slot marker (e.g. shuffling (document, is_oracle) pairs and reading the marker's position), never recovered by searching the shuffled list for the oracle's text. When a drawn distractor chunk has content identical to the oracle's, the reported index is the oracle's own slot, not the first text match.
- **observability** — Chunks ["alpha","bravo","charlie","delta","echo"], distractors=2, p=1.0, sampler=lambda pop,k: list(pop)[:k], rng whose random() returns 0.0 and whose shuffle is a no-op: parse({"chunk_id": 0, "question": "Q"}, "resp")["context"]["sentences"][0] == ["bravo", "charlie", "alpha"]. Chunks ["same","same","other","third"], distractors=2, p=1.0, same head sampler and no-op shuffle, chunk_id=0: sentences[0] == ["same","other","same"] and oracle_index == 2. With the rng-bound default sampler and p=0.0, a SpyRng recording calls logs exactly ["random", "sample", "shuffle"] and the spy sampler records one call ([1,2,3,4], 3).
- *earlier, reversed*: The team first shipped the shortest fix — keep the oracle prepended and compute oracle_index = documents.index(oracle_document) after the shuffle — and reversed it after a corpus with duplicated boilerplate chunks produced rows whose oracle_index pointed at a distractor; the shuffle was also briefly dropped from the oracle-absent branch as a 'no-op cleanup' and restored to keep the two branches' rng streams identical.

## r2
- **rule** — The document-set builder takes a third positional parameter `question` and is memoised as functools.lru_cache(maxsize=512) over the bound method, keyed on (chunk_id, oracle_document, question); parse calls it positionally in that order. `question` participates in the cache key and in nothing else — it is not used to build documents. The oracle coin is therefore drawn once per (chunk_id, question) pair: two different questions from one chunk get independent coins, and a repeated (chunk_id, question) replays the memoised set without touching the rng.
- **scope** — Before any randomness is consumed on an uncached call, the builder computes available = len(self.chunks) - 1 and requested = self.distractors + 1 — the oracle-absent worst case, regardless of how the coin would land — and rejects the call when available < requested. The check is not made per branch and not deferred to the sampler, so a corpus with len(chunks) - 1 == distractors fails on every chunk deterministically rather than only on chunks that happen to draw the absent branch.
- **failure_behavior** — Raise a new module-level `InsufficientDistractorsError(ValueError)` constructed as InsufficientDistractorsError(chunk_id=chunk_id, requested=requested, available=available), carrying exactly the attributes chunk_id, requested, available, with str(exc) == f"chunk {chunk_id}: requested {requested} distractors, only {available} available". No rng call and no sampler call is made before it is raised.
- **observability** — Five-chunk fixture, head sampler, SpyRng(7): calling the builder with (0,"alpha","Q1"), (0,"alpha","Q2"), (0,"alpha","Q1"), (1,"bravo","Q1") gives cache_info() == CacheInfo(hits=1, misses=3, maxsize=512, currsize=3) and rng.calls.count("random") == 3. Chunks ["a","b","c","d"], distractors=3, p=1.0, head sampler, SpyRng(7): parse({"chunk_id": 2, "question": "Q"}, "resp") raises InsufficientDistractorsError, isinstance(exc, ValueError) is True, (exc.chunk_id, exc.requested, exc.available) == (2, 4, 3), str(exc) is the message above, and rng.calls == [].
- *earlier, reversed*: The cache was originally keyed on (chunk_id, oracle_document) at maxsize=128, and the team briefly proposed 'fixing' the docstring to say per-chunk instead; they reversed to the per-question key. They also first let random.sample's plain ValueError surface, and reversed after the small-corpus failures proved coin-dependent and unreproducible.
