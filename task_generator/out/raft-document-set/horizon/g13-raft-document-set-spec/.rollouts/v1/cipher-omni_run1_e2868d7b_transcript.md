- `InsufficientDistractorsError(ValueError)` — constructed with `chunk_id`, `requested`, `available`, carrying those attributes and the message `"chunk {chunk_id}: requested {requested} distractors, only {available} available"`.

**`Raft` dataclass:** Two new fields appended after `answer_generator_cls`: `question_generator_cls: type | None = None` and `sampling: RaftSampling | None = None`. Tail order is `["answer_generator_cls", "question_generator_cls", "sampling"]`; existing fields keep names/defaults/order. `Raft` does not validate `p`/`distractors`.

**`Raft.__call__`:** Resolves `question_cls`/`answer_cls`/`sampling` seams first, constructs both stages with the exact keyword arguments specified (passing `n` to both, and `sampler`/`rng` on every run including `None`). The list branch drops entries whose `str.strip()` is empty and renumbers survivors contiguously from `0`; the str branch is unchanged. **`_RaftAnswer.__init__`:** New `rng` and `sampler` parameters; validates `p` (closed interval) then `distractors` (≥1) before `super().__init__`, raising plain `ValueError`. Sets `rng` (given or fresh `random.Random()`), `sampler` (given or `self.rng.sample`), `formatter`, and `self.stats = RaftDrawStats()`. `lru_cache(maxsize=512)` wraps the bound `_get_document_set`.

**Document-set builder:** First statement is the no-randomness `InsufficientDistractorsError` check using the oracle-absent worst case. Each build: one `self.rng.random()` coin, one `self.sampler(available_indices, k)`, one `self.rng.shuffle(...)` over `(document, marker)` pairs in both branches. Oracle-present appends the oracle at the end pre-shuffle and tracks its slot via a per-slot marker (not text search); oracle-absent sets `oracle_index = -1`.

**`parse`:** Passes `(chunk_id, oracle_document, question)` positionally to the memoised builder; returns exactly the seven specified keys with `oracle_index` taken verbatim from the `DocumentSet` (no re-derivation), and `context`/`instruction` built per spec.
