- `rng: Optional[random.Random] = None`

**`Raft` dataclass** — two new fields appended after `answer_generator_cls`:
- `question_generator_cls: type | None = None`
- `sampling: RaftSampling | None = None`
- Tail order is now `["answer_generator_cls", "question_generator_cls", "sampling"]`; existing fields keep their names/defaults/order.

**`Raft.__call__`** wiring:
- Resolves the three seams first: `question_cls`, `answer_cls`, `sampling` (defaulting to `RaftSampling()`).
- Builds both stages with the exact keyword-argument shapes specified, passing `n` to both (question generator's existing `n` kwarg is finally used), and `sampler`/`rng` on every run (even when `None`).
- List branch drops entries whose `str.strip()` is empty and renumbers survivors contiguously from `0`.
- Still annotated `-> datasets.Dataset`, still returns the `CuratorResponse` from `answer_gen(questions)`.

**`_RaftAnswer.__init__`** — new signature with `sampler` and `rng` params, validates `p` then `distractors` before `super().__init__`, sets `self.rng` (fresh `random.Random()` if none), `self.sampler` (defaults to `self.rng.sample`), `self.stats = RaftDrawStats()`.

**Document-set builder** (`_get_document_set`):
- Takes a third positional param `question` (participates in memoisation key), wrapped in `functools.lru_cache(maxsize=512)`.
- First statement is the `InsufficientDistractorsError` check (worst-case oracle-absent `requested = distractors + 1`), consuming no randomness.
- Order of rng draws: (1) `self.rng.random()` coin, (2) `self.sampler(...)` draw, (3) `self.rng.shuffle(...)` in both branches (same rng stream shape).
- Oracle-present: distractors in sampler order with oracle **appended at the end**, then shuffle. `oracle_index` is tracked by a per-slot boolean marker carried through the shuffle (not by text search), so it's correct even when a distractor's content equals the oracle's.
- Oracle-absent: `oracle_index = -1` (only place the sentinel is produced).
- Increments `RaftDrawStats` per build; memoised replays increment nothing.

**`parse`** — returns exactly the seven specified keys, reports `doc_set.oracle_index` verbatim (no re-derivation), passes `(chunk_id, oracle_document, question)` positionally to the builder.

**New `RaftDrawStats`** (mutable dataclass) with `document_sets`/`with_oracle` counters and `oracle_rate()`.

**New `InsufficientDistractorsError(ValueError)`** carrying `chunk_id`/`requested`/`available` with the specified message.
