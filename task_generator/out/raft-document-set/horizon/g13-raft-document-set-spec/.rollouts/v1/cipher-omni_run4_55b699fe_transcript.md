### Changes to `raft.py`

**New module-level types (after `_ContextFormatter`):**
- `RaftDrawStats` (mutable `@dataclass`): fields `document_sets: int = 0`, `with_oracle: int = 0` (in that order), with `oracle_rate()` returning `with_oracle/document_sets` (and `0.0` when empty).
- `InsufficientDistractorsError(ValueError)`: constructed with `(chunk_id, requested, available)`, carrying those attributes and the message `"chunk {id}: requested {req} distractors, only {avail} available"`.
- `RaftSampling` (`@dataclass(frozen=True)`): fields `sampler: Optional[_SamplingStrategy] = None`, `rng: Optional[random.Random] = None` (in that order). Assignment to a field raises `FrozenInstanceError`.

**`Raft` dataclass:** appended `question_generator_cls: type | None = None` and `sampling: RaftSampling | None = None` after `answer_generator_cls` (which keeps its position). Existing fields/names/defaults/order unchanged.

**`Raft.__call__`:**
- Resolves `question_cls`, `answer_cls`, and `sampling` first.
- Builds both stages with exactly the specified keyword arguments (passing `n`, `distractors`, `p`, `sampler`, `rng` through to the answer generator, including when they are `None`).
- In the list branch, drops entries whose `str.strip()` is empty and renumbers survivors contiguously from `0`; the `str` branch is unchanged.
- Keeps the `-> datasets.Dataset` annotation while returning the `CuratorResponse`.

**`_RaftAnswer.__init__`:** validates `p` (before `distractors`, before `super().__init__`) raising plain `ValueError`, then sets `n`, `distractors`, `p`, `chunks`, `rng` (given or fresh `random.Random()`), `sampler` (given or `self.rng.sample`), `formatter`, `stats = RaftDrawStats()`, and wraps `_get_document_set` with `functools.lru_cache(maxsize=512)`.

**`_get_document_set(chunk_id, oracle_document, question)`:**
- First statement: `available = len(chunks) - 1`, `requested = distractors + 1`; raises `InsufficientDistractorsError` if `available < requested` (no randomness consumed).
- One `rng.random()` coin â `oracle_present`; one `sampler(available_indices, k)` (distractors if present, distractors+1 if absent); one `rng.shuffle` over the assembled slot list (both branches, identical rng shape).
- Oracle-present branch builds the pre-shuffle list as distractors (sampler order) with the oracle **appended at the end**, then shuffles. `oracle_index` is tracked by a per-slot marker carried through the shuffle (so a duplicate-content distractor never steals the oracle's slot), reporting the slot **in the returned documents list**.
- Oracle-absent branch reports `oracle_index = -1` (the only `-1` source).
- Increments `stats.document_sets` (and `with_oracle` when present) per build; memoised replays skip this entirely.

**`parse`:** passes `(chunk_id, oracle_document, question)` positionally; returns exactly `question`, `cot_answer`, `oracle_document`, `context`, `instruction`, `oracle_present`, `oracle_index` with `oracle_index` taken verbatim from the `DocumentSet` (no re-derivation, no `... else -1` conditional).
