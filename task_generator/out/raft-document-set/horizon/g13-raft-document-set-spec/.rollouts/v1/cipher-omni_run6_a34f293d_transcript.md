## Summary

I made the `Raft` facade the authoritative owner of sampling knobs and randomness, fixed the `oracle_index` reporting, and added the r1/r2 features. Here's what I changed:

### `src/bespokelabs/curator/blocks/raft.py` (production code)

1. **New `RaftSampling`** â a `@dataclass(frozen=True)` with fields `sampler: Optional[_SamplingStrategy] = None` and `rng: Optional[random.Random] = None`, in that order. Assigning to a field raises `FrozenInstanceError`.

2. **New `RaftDrawStats`** â a mutable `@dataclass` with `document_sets: int = 0`, `with_oracle: int = 0`, and `oracle_rate()` returning `with_oracle/document_sets` (0.0 when empty).

3. **New `InsufficientDistractorsError(ValueError)`** â constructed with `chunk_id`/`requested`/`available`, carrying exactly those attributes, with message `"chunk {chunk_id}: requested {requested} distractors, only {available} available"`.

4. **`Raft` dataclass** â appended two fields after `answer_generator_cls`: `question_generator_cls: type | None = None` and `sampling: RaftSampling | None = None`. Tail order is `["answer_generator_cls", "question_generator_cls", "sampling"]`.

5. **`Raft.__call__`** â resolves the three seams (`question_cls`, `answer_cls`, `sampling`), constructs the question stage with `n=self.n_questions`, constructs the answer stage with the exact keyword arguments specified (including `n`, `sampler`, `rng`), and the list branch drops blank/whitespace-only entries and renumbers survivors contiguously. Still returns the `CuratorResponse`.

6. **`_RaftAnswer.__init__`** â validates `p` (before `distractors`) and `distractors` before `super().__init__`, raising plain `ValueError`. Sets `rng` (given or fresh `random.Random()`), `sampler` (given or `self.rng.sample`), `formatter`, and `stats = RaftDrawStats()`. The lru_cache is now `maxsize=512`.

7. **`_get_document_set`** â now takes a third positional param `question` (part of the memoisation key). First statement is the `InsufficientDistractorsError` check (`available = len(chunks)-1`, `requested = distractors+1`, raises when `available < requested`, consuming no randomness). Then: one `rng.random()` for the coin; one `sampler` draw; one `rng.shuffle` over the assembled list in both branches. The oracle-present branch appends the oracle at the end and tracks its slot via a per-slot marker through the shuffle (so duplicate-content distractors don't confuse the index). The absent branch produces `oracle_index = -1` (the only place the sentinel is produced). Stats are incremented on each actual build.

8. **`parse`** â passes `(chunk_id, oracle_document, question)` positionally; returns `oracle_index` verbatim from `doc_set` (no re-derivation); returns `Dict[str, Any]`.
