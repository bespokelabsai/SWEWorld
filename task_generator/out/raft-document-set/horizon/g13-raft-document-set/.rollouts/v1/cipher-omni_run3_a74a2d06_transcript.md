- Each build performs, in this order:
  1. one `self.rng.random()`, compared `< self.p`, giving `oracle_present`;
  2. one `self.sampler(available_indices, k)`, where `available_indices == [i for i in range(len(self.chunks)) if i != chunk_id]` in ascending order, and `k = self.distractors` when the oracle is present, `self.distractors + 1` when it is absent;

- Oracle-present branch: the pre-shuffle list is the distractors in sampler order with the oracle document **appended at the end** (the current code prepends it at `raft.py:156`), then the single shuffle permutes it.
- `oracle_index` is the oracle's slot **in the list returned as `DocumentSet.documents`** — the same list the context and `instruction` are built from (`raft.py:125, 130`). Track it by carrying a per-slot marker through the shuffle, not by searching the shuffled list for the oracle's text: when a distractor chunk has content identical to the oracle's, the oracle's own slot is reported. `raft.py:169` reports the pre-shuffle index today.
- Oracle-absent branch: `oracle_index = -1`, and this is the only place the `-1` sentinel is produced.

## Summary

I modified `src/bespokelabs/curator/blocks/raft.py` and added `tests/unit/blocks/test_raft.py` to make the `Raft` facade the authoritative owner of the sampling knobs and randomness, and to make `oracle_index` agree with the documents actually emitted.

### Changes to `raft.py`

**New module-level `RaftSampling`** (frozen dataclass, after the `_SamplingStrategy` Protocol):
- Two fields in order: `sampler: Optional[_SamplingStrategy] = None`, `rng: Optional[random.Random] = None`.
- `RaftSampling() == RaftSampling(sampler=None, rng=None)`; field assignment raises `FrozenInstanceError`.

**`Raft` dataclass**: appended two new fields after `answer_generator_cls`:
- `question_generator_cls: type | None = None`
- `sampling: RaftSampling | None = None`
- Tail order is now `["answer_generator_cls", "question_generator_cls", "sampling"]`; existing fields/names/defaults/order preserved.

**`Raft.__call__`**: resolves the three seams first (`question_cls`, `answer_cls`, `sampling`), then constructs both stages with exactly the specified keyword arguments â passing `n`, `distractors`, `p`, `sampler`, and `rng` to the answer stage (and `n` to the question stage), every run, even when `None`. The `str` branch, annotation (`-> datasets.Dataset`), and `CuratorResponse` return value are unchanged.

**`_RaftAnswer.__init__`**: new signature with `rng: Optional[random.Random] = None`. Sets `rng` (given or a fresh `random.Random()`), `sampler` (given or `self.rng.sample`), `formatter`, and keeps the `functools.lru_cache` wrapping and `**kwargs` passthrough.

**Document-set builder** (`_get_document_set`, name/return type/cache preserved): per build, in order â (1) `self.rng.random() < self.p` â `oracle_present`; (2) `self.sampler(available_indices, k)` with `k = distractors` (present) or `distractors + 1` (absent), `available_indices` ascending and excluding `chunk_id`; (3) one `self.rng.shuffle` over assembled `(document, is_oracle)` pairs in **both** branches (same rng-stream shape). Oracle-present branch appends the oracle document at the end before shuffle; `oracle_index` is the oracle's slot in the returned list, tracked by a per-slot marker that rides through the shuffle (so duplicate distractor content still reports the oracle's own slot). Oracle-absent branch sets `oracle_index = -1` (the only place the sentinel is produced).

**`parse`**: returns exactly the seven specified keys; `oracle_index` and `oracle_present` come verbatim from `doc_set` (the old `... if doc_set.oracle_present else -1` conditional is gone); `instruction` uses `self.formatter(docs) + "\n" + question`.

No draw reads the module-level `random` anymore; no new dependencies.
