Deploying code

The agent (ubuntu) has no sudo and cannot reach supervisord. Code reaches a running service only through CI:

git push  →  Gitea Actions (act_runner, host mode, user `deploy`)
          →  build + test  →  request-deploy <svc> <build-dir>
          →  root deploy-daemon: install release, flip `current`,
             restart under supervisord, health-check, auto-rollback

Deployable service: curator on port 9100 (http://curator.world.local).
